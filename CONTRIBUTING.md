# Contribuer à Fluency

Fluency est une app locale d’apprentissage de l’anglais, avec profil configurable et IA facultative. Vous pouvez enrichir les contenus sans ajouter de fournisseur IA.

Commencez par [le guide des contenus](docs/AJOUTER_DU_CONTENU.md). Une contribution pédagogique doit avoir un objectif précis, des exemples originaux, des traductions naturelles et des explications utiles après une erreur. Utilisez un niveau indicatif adapté au sens présenté ; la longueur, le registre soutenu et la rareté ne suffisent pas à définir un niveau avancé.

Pour signaler un problème, donnez la version de l’app, la page concernée, l’identifiant de la fiche ou de l’exercice, les étapes de reproduction, puis le résultat attendu. Pour une correction linguistique, ajoutez le contexte qui explique pourquoi une autre réponse est valable.

Avant de proposer un changement, exécutez les contrôles indiqués dans le guide, puis testez le parcours concerné dans le navigateur avec l’IA désactivée. Vérifiez que les exemples et la progression restent accessibles sur mobile.

Pour préparer un dépôt partageable, conservez les sources, les fichiers JSON, les guides, les scripts et `package-lock.json`. Les répertoires de dépendances, de compilation, les sauvegardes personnelles et la configuration IA locale ne doivent pas être ajoutés au dépôt. Le fichier `.gitignore` exclut déjà les dépendances, les sorties de Next.js, les variables d’environnement et la configuration privée.
